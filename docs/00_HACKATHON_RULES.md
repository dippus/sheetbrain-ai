## 2. Mandatory Eligibility & Gate Criteria

### Gate 1: Participant Eligibility
* **Age**: 18+ years of age.
* **Profile**: Active and verified `builder.aws.com` profile.
* **Originality**: Must be an original, unpublished project created during the hackathon window.
* **Entry Cap**: Maximum 1 entry per participant. Individuals or teams of up to 5.

### Gate 2: The "Ship Gate" (Hard Pass/Fail)
* **Live App Mandatory**: Application must be deployed live on AWS and be publicly reachable.
* **Zero Exceptions**: Projects without an active public URL hosted on AWS infrastructure do NOT advance to judging.

### Gate 3: AI Coding Agent Connection & Evidence
* **Mandatory AI Usage**: Participants must connect an AI coding agent to the AWS console.
* **Documented Proof**: Must provide documented evidence showing:
  1. The coding agent was connected to AWS.
  2. How the AI agent helped throughout the development journey.
  3. Chronological builder logs published on the Builder Center project entry.

---

## 3. Two-Stage Judging Evaluation Process

### Round 1: AI Scoring (Screening Gate)
All qualifying submissions that pass the Ship Gate are evaluated across 4 equal criteria (25% each):
1. **Technical Innovation & Originality (25%)**: Use of modern cloud architecture and non-trivial AI agent workflows.
2. **Implementation Quality (25%)**: Code cleanliness, error resilience, responsive UX, and architecture execution.
3. **Community & Market Impact (25%)**: Real-world usefulness, solving high-friction problems ($2B+ spreadsheet productivity).
4. **Creativity & Storytelling (25%)**: Quality of the project story, demo video, and documented development journey.

### Round 2: Human Judging Panel (Top 100 Finalists)
* The top 100 highest-scoring projects advance to Gate 2.
* An expert panel of AWS Solutions Architects reviews the finalists to select the 5 category winners.
